# ☕ Aroma Coffee — лендинг кофейни

Одностраничный адаптивный сайт-визитка для кофейни, выполненный в тёплой, «уютной» цветовой палитре. Проект создан как учебно-демонстрационная работа для портфолио и фокусируется исключительно на фронтенд-вёрстке: чистая структура, современный CSS (Flexbox, Grid), продуманная адаптивность под десктоп, планшет и мобильные устройства.

> **Статус проекта:** в разработке. На данный момент реализована фронтенд-структура сайта (HTML + CSS) без бэкенда и интерактивной логики — кнопки заказа и формы носят демонстрационный характер.

---

## 🎯 Цель проекта

Показать уверенное владение современной CSS-вёрсткой без использования готовых фреймворков (Bootstrap, Tailwind и т.п.) — вся раскладка написана вручную, чтобы продемонстрировать понимание:

- Flexbox и CSS Grid как инструментов построения сложных сеток
- принципов адаптивного дизайна (media queries, `flex-wrap`, изменение направления потока)
- работы с типографикой и подключением веб-шрифтов
- построения переиспользуемых, консистентных компонентов (карточки товаров, отзывов, блоков преимуществ)
- аккуратной организации кода: понятные имена классов, разделение по секциям, отсутствие «хаков»

## 🧩 Структура сайта

Лендинг состоит из следующих смысловых блоков:

| Секция | Назначение |
|---|---|
| **Header** | Липкая навигация (`position: sticky`) с логотипом, меню и CTA-кнопкой |
| **Hero** | Приветственный экран с фоновым изображением, слоганом и ключевой статистикой (годы работы, количество чашек, страны-поставщики) |
| **Details / Advantages** | Блок из 4 карточек-преимуществ на Flexbox с иконками Font Awesome |
| **Menu** | Каталог напитков — карточки на CSS Grid с изображением, тегом, ценой и описанием |
| **About Us** | История бренда: изображение с наложением (`text_overlay`) и текстовый блок с фактами о компании |
| **Gallery** | Асимметричная фотогалерея на именованных областях CSS Grid (`grid-template-areas`) |
| **Testimonials** | Блок отзывов клиентов: карточки с рейтингом, цитатой и профилем автора (аватар-инициалы + имя/профессия), выровненные по нижнему краю независимо от длины текста |
| **Contact / Relations** | Контактная информация и блок с картой/адресом |

## 🛠️ Технологии

- **HTML5** — семантичная структура (`<section>`, `<nav>`, `<header>`)
- **CSS3**
  - Flexbox — для навигации, карточек, горизонтальных и вертикальных выравниваний
  - CSS Grid — для меню, галереи и адаптивных сеток
  - Media Queries — брейкпоинты под десктоп (1024px) и мобильные устройства (700px)
  - Кастомные CSS-переменные и цветовая палитра в стиле «кофейных» тонов
- **Google Fonts** — `Cormorant`, `Playfair Display`, `Inter` для сочетания элегантной и функциональной типографики
- **Font Awesome 6** — иконки (кружка, награда, доставка, команда, звёзды рейтинга, локация, телефон, почта, часы)

## 📱 Адаптивность

Вёрстка построена mobile-first-совместимо и тестировалась на трёх основных ширинах экрана:

- **Desktop** (от 1024px) — полноценная многоколоночная раскладка
- **Tablet** (до 1024px) — карточки переносятся в 2 колонки через `flex-wrap`
- **Mobile** (до 700px) — блоки выстраиваются в одну колонку (`flex-direction: column`), галерея переключается на упрощённую grid-сетку
