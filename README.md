## 📖 О проекте

**Aroma Coffee** — лендинг для вымышленной специализированной кофейни в Портленде (Pearl District). Проект создан как учебная работа по вёрстке: адаптивная сетка на Flexbox и CSS Grid, работа с типографикой, доступность навигации, семантичная разметка и аккуратная работа с изображениями (object-fit, оверлеи, градиенты).

Никакого JavaScript в проекте нет — вся интерактивность (мобильное меню, hover-эффекты, плавный скролл) реализована средствами чистого CSS.

## ✨ Ключевые фичи

- **Плавная навигация** — клик по пункту меню плавно скроллит к нужной секции (`scroll-behavior: smooth`), с учётом высоты sticky-шапки (`scroll-margin-top`).
- **Мобильное меню без JS** — бургер-меню реализовано на чистом CSS через `<input type="checkbox">` + `label`.
- **Оверлеи с градиентом** — на фото в блоках "О нас" и "Контакты" использован фирменный коричневый градиент (`#2C1A0E`) для читаемости белого текста поверх изображений.
- **Микроанимации** — hover-подъём карточек (`translateY`), увеличение фото при наведении (`scale`), анимированное подчёркивание пунктов меню.
- **Единая типографика** — `Playfair Display` для заголовков, `Inter` для остального текста, заданные глобально через `body` и селекторы заголовков.

## 📱 Адаптивность

Брейкпоинты: `1024px`, `900px`, `700px`, `600px`, `500px`.

| Секция | Поведение на мобильных |
|---|---|
| Header | Меню сворачивается в бургер |
| Hero | Уменьшается заголовок и статистика |
| Menu | Сетка 3 → 2 → 1 колонка |
| Gallery | Grid-раскладка перестраивается под 2 колонки |
| Reviews | Карточки в 2, затем в 1 колонку |
| Contact | Карточки и фото складываются в вертикальную колонку |
| Footer | Три колонки складываются вертикально |
